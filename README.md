# جحفل | Jahfal Perfumes

صفحة رئيسية لبراند عطور جحفل، مبنية بـ HTML و CSS.

🔗 المعاينة: https://waleedhossam2.github.io/project/

## المميزات

- شعار ذهبي فخم
- هيدر ثابت أثناء التمرير
- صورة خلفية بكامل الشاشة


## الملفات

- `index.html`: بنية الصفحة (الهيدر والشعار والقسم الرئيسي)
- `style.css`: الألوان والتنسيقات والحركات
- `hero.jpg`: صورة الخلفية
- `logo.svg`: ملف الشعار

## التشغيل

حمّل الملفات وافتح `index.html` بالمتصفح.
